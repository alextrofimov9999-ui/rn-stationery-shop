# Вход в аптеку

Для установки зависимостей запусти `npm install` (эта команда также обновит package-lock.json). Затем запусти `npx expo start` и открой приложение на Android или iOS. Для тестового входа используй `admin` / `password`. Это учебные данные; настоящие пароли сюда добавлять нельзя.

## Вход через GitHub

1. В GitHub открой Settings → Developer settings → OAuth Apps → New OAuth App.
2. Для учебной настройки укажи Homepage URL `http://localhost` и callback URL `http://localhost/callback`. В этом сценарии callback не используется.
3. В настройках OAuth App включи Enable Device Flow. Этот режим здесь используется для учебного запуска без сервера; не включай его в рабочем приложении без необходимости.
4. В корне проекта создай `.env.local` со строкой `EXPO_PUBLIC_GITHUB_CLIENT_ID=твой_client_id`. Client Secret не нужен: не добавляй его ни в `.env.local`, ни в код.
5. Перезапусти Expo. Нажми «Войти через GitHub», открой GitHub по кнопке и введи код с экрана приложения. Подтверждай только код, который сам запросил. Магазин откроется после того, как GitHub подтвердит вход.

## Проверка

- При вводе пароль отображается точками. Неверный пароль не открывает магазин.
- На Android и iOS попробуй снять скриншот на экране входа, затем повтори после входа. Защита применяется только на экране входа. В браузере блокировки нет; проверяй GitHub-вход на телефоне.
- Если используешь собственную development build, пересобери её после добавления нативной зависимости.
